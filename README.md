# AI-Powered Customer Segmentation System

## 📌 Project Overview

This project is an AI-based Customer Segmentation System developed for SmartCart, a growing e-commerce platform serving customers across multiple countries.

The system uses **Unsupervised Machine Learning** techniques to analyse customer behaviour and automatically group customers into meaningful clusters based on:

- Purchasing behaviour
- Customer engagement
- Loyalty indicators
- Website activity
- Demographic information

The main objective of this project is to help businesses perform:

- Personalized marketing
- Customer retention
- Churn identification
- Targeted promotions
- Business intelligence analysis
